    This is the short version. The full setup guide covers Paddle onboarding, website approval, testing, going live and troubleshooting.

    1. Create a Paddle API key

    1. In Paddle, go to Developer tools → Authentication → API keys → New API key.
    2. Grant: customer.read customer.write transaction.read transaction.write adjustment.read adjustment.write subscription.read payment_method.read notification_setting.read notification_setting.write client_token.write, and checkout_domain.read so the dashboard can show your domain approval. To manage everything from this dashboard, also add subscription.write discount.read discount.write report.read report.write notification.read notification.write customer_portal_session.write.
    3. Sandbox keys start with pdl_sdbx_, live keys with pdl_live_. Paste it under Connections.

    2. Approve your checkout domain

    1. In Paddle Checkout → Checkout settings, set a default payment link on an approved domain. Paddle won't open checkout without it.
    2. Live accounts: your website must be approved in Checkout → Website approval.
    3. If checkout spins and never loads, this step is almost always the cause.

    3. Turn it on in your CRM

    1. Open Payments → Integrations, find Paddle Pay and click Set as default.
    2. Use test mode with sandbox key and card 4242 4242 4242 4242, any future expiry, CVC 100.
    3. Switch your CRM's payments to live mode once the live key is connected.
