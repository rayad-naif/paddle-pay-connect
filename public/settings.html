How to create the API key
  1. In Paddle, go to Developer tools → Authentication → API keys → New API key.
  2. Grant these permissions: customer.read customer.write transaction.read transaction.write adjustment.read adjustment.write subscription.read payment_method.read notification_setting.read notification_setting.write client_token.write.
  3. Copy the key and paste it here. Sandbox keys start with pdl_sdbx_, live keys with pdl_live_.
  4. In Paddle Checkout → Checkout settings, make sure a default payment link is set on an approved domain.
  5. Back in HighLevel, open Payments → Integrations and set this provider as default.
